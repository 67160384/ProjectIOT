# บทคลิปสาธิต 4–5 นาที

ต้องอัดระบบและ Raspberry Pi จริง ไฟล์นี้เป็นบทเตรียมถ่าย ไม่ใช่คลิปที่ส่งแล้ว

| เวลา | ภาพที่ถ่าย | สิ่งที่อธิบาย |
|---|---|---|
| 0:00–0:25 | ผู้จัดทำ + ชื่อโครงงาน | ปัญหาการเก็บใบเสร็จและบันทึกค่าใช้จ่ายด้วยมือ |
| 0:25–0:55 | Pi, มือถือ, ภาพ architecture | Pi รัน OCR/LLM/SQLite; มือถือใช้เว็บผ่าน Wi-Fi เดียวกัน |
| 0:55–1:20 | หน้าอัปโหลด + ใบเสร็จจริง | ถ่ายภาพชัดและอัปโหลด JPG/PNG |
| 1:20–2:10 | การประมวลผล + ผล OCR/AI | แสดงเวลาจริง ถ้าตัดต่อช่วงรอให้ระบุเวลาที่ข้าม ห้ามแสดงผลกรอกเองเป็นผล AI |
| 2:10–2:50 | หน้าตรวจแก้ | แก้ช่องที่ผิด ทดลองยอดไม่ตรง แสดงคำเตือนและเหตุผลส่วนลด |
| 2:50–3:20 | ยืนยัน + Dashboard | รายจ่ายรวม กราฟหมวดหมู่ ประวัติและรายละเอียด |
| 3:20–3:55 | ตัด WAN แล้วอัปโหลดใบใหม่ | คง LAN และพิสูจน์ว่า OCR + AI ทำงานในเครื่องจริง |
| 3:55–4:30 | ตารางผลทดสอบจริง | เวลา ความถูกต้องจากชุดทดสอบ จำนวนที่ต้องแก้ และข้อจำกัด Pi 4 |
| 4:30–5:00 | ผู้จัดทำ + สรุป | จุดเด่นการประยุกต์ แนวทางต่อยอด เช่นชุดข้อมูลมากขึ้นและรองรับใบเสร็จยาว |

เตรียมภาพนิ่งอุปกรณ์ 1 ภาพ, ผังระบบ, ใบเสร็จที่ได้รับอนุญาต 2 รูปแบบ, ตารางผลทดลอง และสำรองข้อมูลก่อนสาธิต ปิดหรือเบลอข้อมูลส่วนตัวก่อนเผยแพร่คลิป
