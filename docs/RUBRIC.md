เกณฑ์ยก sensor หลายตัว, dashboard, AI เป็นตัวอย่างของการเชื่อมหลายองค์ประกอบ ไม่ได้ระบุว่าทุกโครงงานต้องใช้ sensor แต่ควรให้อาจารย์ยืนยันว่าแนว Edge AI บน Raspberry Pi เชื่อมมือถือผ่าน LAN ตรงขอบเขตรายวิชา IoT การไม่มีอุปกรณ์เซนเซอร์ไม่ควรถูกอธิบายว่าผ่านวิชาโดยอัตโนมัติ

## เป้าหมาย Progress 1 ที่เสนอ

1. เปิดเว็บจากมือถือใน Wi-Fi เดียวกันได้
2. OCR ไทย/อังกฤษบน Pi ได้จากใบเสร็จจริงอย่างน้อย 2 รูปแบบ
3. โมเดลท้องถิ่นคืน JSON และระบุข้อมูลที่ต้องตรวจแก้
4. ยืนยันบันทึกและ Dashboard แสดงยอดถูกต้อง
5. มีผลทดสอบและรายการข้อจำกัดจริง ไม่ใช่เพียงภาพหน้าเว็บ

## แนวคิดนวัตกรรมที่อ้างได้อย่างระมัดระวัง

“นำ OCR และโมเดลภาษาขนาดเล็กมาประยุกต์บน Raspberry Pi เพื่อช่วยบันทึกรายจ่ายจากใบเสร็จไทยโดยไม่ส่งภาพไปบริการ AI ภายนอก และออกแบบให้ผู้ใช้ตรวจสอบยอดรวมกับหลักฐานต้นฉบับก่อนบันทึก”

ทำตารางเปรียบเทียบกับการกรอกเองและบริการสแกนใบเสร็จที่ศึกษา: ต้องใช้อินเทอร์เน็ตหรือไม่, ข้อมูลถูกส่งออกหรือไม่, แก้ไขข้อมูลได้หรือไม่, ค่าใช้จ่าย, และเวลาที่ใช้ ห้ามใส่ผลที่ยังไม่วัด
