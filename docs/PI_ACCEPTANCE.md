## ตรวจพร้อมใช้งาน

- [ ] `uname -m` ได้ aarch64
- [ ] `tesseract --list-langs` มี tha และ eng
- [ ] `scripts/check_ready.py` ผ่าน
- [ ] มือถือเข้าเว็บผ่าน LAN ได้
- [ ] ภาพทดสอบเก็บเป็นส่วนตัวและได้รับอนุญาตให้ใช้

## ทดสอบครบกระบวนการ

- [ ] ใบเสร็จจริง 2 รูปแบบผ่าน Upload → OCR → Local LLM → Review → Save → Dashboard
- [ ] ภาพเอียง/เบลอมีข้อความแจ้งหรือแก้ได้ ไม่มีบันทึกอัตโนมัติ
- [ ] จำนวน 2 ชิ้นไม่ถูกคูณซ้ำกับยอดรวมบรรทัด
- [ ] ส่วนลด/ภาษี/ค่าบริการตรวจสอบยอดตรง
- [ ] ยอดต่างต้องยืนยัน และแสดงส่วนต่างในกราฟ
- [ ] ไฟล์ปลอมและไฟล์เกินขนาดถูกปฏิเสธ
- [ ] กดยืนยันซ้ำไม่เกิดใบเสร็จซ้ำ
- [ ] ใบที่ไม่ยืนยันไม่ถูกนับใน Dashboard
- [ ] ตัดอินเทอร์เน็ตขาออก คง LAN และอัปโหลดภาพใหม่ได้ครบกระบวนการ
- [ ] รีบูต Pi แล้วบริการเริ่มใหม่และข้อมูลยืนยันยังอยู่
- [ ] เปิดต่อเนื่องและทดลอง 10 ใบ ไม่มีโปรเซสล้ม/หน่วยความจำหมด
- [ ] บันทึกอุณหภูมิและสถานะ throttling (`vcgencmd measure_temp`, `vcgencmd get_throttled` ถ้ามี)
- [ ] ให้ผู้ใช้คนอื่นทำตามคู่มือ แล้วบันทึกจุดที่ทำไม่ได้

เมื่อทดสอบล้มเหลวให้เก็บเหตุการณ์จริงและ log ที่ไม่มีข้อมูลส่วนตัว อย่าเปลี่ยนเป็น “ผ่าน” เพราะใช้กรอกเองแทน AI ได้
