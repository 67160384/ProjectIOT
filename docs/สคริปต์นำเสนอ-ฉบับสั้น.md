# สคริปต์นำเสนอ “ใบเสร็จดี” ฉบับสั้น

## สไลด์ 1 — ชื่อโครงงาน

โครงงานใบเสร็จดีเป็นเว็บไซต์วิเคราะห์ใบเสร็จด้วย OCR และ Local AI บน Raspberry Pi โดยข้อมูลทั้งหมดประมวลผลอยู่ภายในเครื่อง

## สไลด์ 2 — ปัญหาและเป้าหมาย

การบันทึกใบเสร็จด้วยมือใช้เวลาและพิมพ์ผิดได้ ระบบจึงช่วยอ่านและกรอกข้อมูลอัตโนมัติ แต่ยังให้ผู้ใช้ตรวจแก้ก่อนบันทึก

## สไลด์ 3 — โครงสร้างระบบ

โทรศัพท์ส่งภาพผ่าน Wi-Fi ภายในไปยัง Flask บน Raspberry Pi จากนั้น OCR และ Local LLM วิเคราะห์ข้อมูล ก่อนบันทึกใน SQLite และแสดง Dashboard

## สไลด์ 4 — ลำดับการทำงาน

ขั้นตอนคืออัปโหลด ปรับภาพ อ่าน OCR วิเคราะห์ด้วย Parser และ LLM ตรวจแก้ บันทึก และดู Dashboard

## สไลด์ 5 — เทคโนโลยี

Flask ทำ Backend, Pillow เตรียมภาพ, Tesseract อ่านตัวอักษร, Qwen วิเคราะห์ข้อความผ่าน llama.cpp, SQLite เก็บข้อมูล และ Chart.js แสดงกราฟ

## สไลด์ 6 — LLM

OCR อ่านตัวหนังสือจากภาพ ส่วน LLM ทำความเข้าใจว่าข้อความคือชื่อร้าน สินค้า จำนวน หรือราคา โมเดลรับข้อความจาก OCR และทำงานภายใน Raspberry Pi

## สไลด์ 7 — หน้าจอระบบ

ระบบมีหน้าอัปโหลด หน้าตรวจแก้ และ Dashboard ผู้ใช้สามารถแก้ทุกช่อง พิมพ์หมวดหมู่ และส่วนลดก่อนยืนยัน

## สไลด์ 8 — ผลและข้อจำกัด

ระบบเปิดใช้งานบน Pi ได้และ automated tests ผ่าน 50 กรณี แต่ความแม่นยำขึ้นกับคุณภาพภาพและรูปแบบใบเสร็จ จึงต้องให้ผู้ใช้ตรวจผลทุกครั้ง

## สไลด์ 9 — สรุป

จุดเด่นคือ OCR อ่าน LLM ช่วยเข้าใจ ผู้ใช้ตรวจสอบ และ Dashboard สรุป โดยไม่ต้องส่งใบเสร็จไปยัง Cloud AI ระหว่างใช้งาน
